# 汤启琛个人网站设计

## 目标

创建一个面向研究与教育机会的个人作品网站。网站以“研究者的工作笔记”为叙事，将生命科学兴趣、教育方向和数字工具探索连接起来；它既便于招聘方快速了解能力，也保留个人成长的温度。

## 视觉与语气

- 方向：编辑感、克制、可信、有阅读感。
- 色彩：暖白纸张背景、深墨文字、低饱和青绿色作为链接和重点标记。
- 排版：中文衬线标题搭配清晰的无衬线正文；大留白、细分隔线、简洁编号。
- 动效：首屏内容按层轻柔出现；项目卡片在悬停时显示进度和摘要。遵守减少动态效果偏好。

## 内容架构

1. **首页**：姓名“汤启琛”、身份“研究与教育方向的学习者”、一句简短主张，以及向下探索的入口。
2. **正在构建的轨迹**：以时间与研究主题编排三项真实经历：2025 年大学生创新创业训练计划省赛入围、全国中学生生物竞赛二等奖、2026 年全国微信小程序开发者选手。
3. **研究与实践地图**：展示三个相交方向：生命科学、教育、数字工具；说明用户希望研究问题、支持学习并尝试把工具落地。
4. **关于我**：简短个人自述，突出“生物爱好者”、好奇心和跨领域学习。
5. **联系**：预留邮箱和 GitHub URL；没有真实信息时，不显示虚构联系方式。

## 实现

- 采用无构建步骤的静态 HTML、CSS、JavaScript，保证 GitHub Pages 可直接托管。
- 语义化结构，适配移动端；键盘可用、颜色对比合格，支持 `prefers-reduced-motion`。
- 不依赖服务端、数据库或第三方追踪；个人资料仅在静态内容中展示。
- 提供 `README.md`，说明如何替换联系方式、推送到 GitHub，以及在仓库设置中开启 GitHub Pages。

## 测试与验证

- 本地用浏览器检查桌面和移动宽度下的布局、导航、链接和动画偏好。
- 检查 HTML 结构与页面内容无虚构经历。
- GitHub Pages 发布后，确认主页和静态资源均能通过 HTTPS 加载。

## 边界

- 本轮不收集或捏造简历、照片、邮箱、社交帐号或研究细节。
- 后续可以在现有结构中添加完整项目案例、论文、教学活动或中英文切换。
